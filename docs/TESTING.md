## 4. 详细用例

### T01 注册、登录、退出

- **步骤与输入**：注册 `alice / secret123`；退出；用错误密码登录；用正确密码登录。
- **预期**：注册成功；错误密码提示「用户名或密码错误」；正确密码提示「欢迎回来」。
- **实际**：通过。

### T02 用户只能看到自己的问卷

- **前置**：alice 创建「Alice 的问卷」；bob 注册。
- **步骤与输入**：bob 访问首页、`/surveys/<alice-id>`、统计页。
- **预期**：首页不包含 alice 的问卷；详情和统计均返回 404。
- **实际**：通过。

### T03 创建四种题型并发布

- **输入**：单选（男/女/其他，必答）、多选（苹果/香蕉/西瓜，1~2 项）、
  文本（2~50 字）、数字（0~120，整数）。
- **预期**：四题写入数据库；题型和 settings 正确；发布后状态 `published`；
  发布后再加题被拒绝，题目数仍为 4。
- **实际**：通过。

### T04 发布前置条件

- **输入**：对无题目问卷调用发布。
- **预期**：提示「至少添加一道题目」，状态仍为 `draft`。
- **实际**：通过。

### T05 单选跳转跳过中间题

- **前置**：4 题；Q1 单选 A/B，规则「等于 a → Q4」。
- **步骤与输入**：开始填写；Q1 选 `a`；观察当前题；答 Q4；提交。
- **预期**：当前题直接变为 Q4；提交后 `path=[Q1,Q4]`；答案值为 `a`、完成文本。
- **实际**：通过。

### T06 多选按包含选项跳转

- **前置**：Q1 多选 A/B/C，规则「包含 c → Q4」。
- **输入**：选择 `a,c`。
- **预期**：当前题直接变为 Q4；提交后 `path=[Q1,Q4]`。
- **实际**：通过。

### T07 数字阈值跳转

- **前置**：Q1 数字 0~120 整数，规则「≥18 → Q3」。
- **输入**：填写 20。
- **预期**：当前题变为 Q3，跳过 Q2。
- **实际**：通过。

### T08 逐题保存与放弃

- **步骤**：开始填写；只答 Q1；查询数据库；POST 放弃。
- **预期**：草稿 `status=in_progress`、`answers` 长度 1、`path=[Q1]`、
  `current_question_id=Q2`；放弃后该问卷无 `in_progress` 文档。
- **实际**：通过。

### T09 匿名提交与重复提交

- **前置**：问卷允许匿名、不允许重复提交；两道文本题。
- **步骤**：匿名开始；答完；提交；再次匿名开始。
- **预期**：答卷 `anonymous=true`，不存在 `respondent_id`，存在 `respondent_key`；
  再次开始提示「不允许重复提交」。
- **实际**：通过。

### T10 必答单选与非法选项

- **输入**：空值；不存在的选项 `z`；合法选项 `a`。
- **预期**：前两次 `400`，分别提示「必答题」「选项不存在」；`a` 进入下一题。
- **实际**：通过。

### T11 多选数量与题目配置边界

- **输入**：3 个选项、最少 2 项；先选 1 项，再选 2 项；
  另建一题「3 个选项、最少 5 项」。
- **预期**：选 1 项 `400` 提示「至少需要选择 2 项」；选 2 项通过；
  非法题目提示「最少选择数量不能超过选项总数」，且未写入数据库。
- **实际**：通过。

### T12 文本长度

- **前置**：必答，3~5 字。
- **输入**：`ab`、`abcdef`、`abc`。
- **预期**：前两次 `400`，分别提示「至少需要输入 3 个字符」「最多只能输入 5 个字符」；
  `abc` 通过。
- **实际**：通过。

### T13 数字范围与整数

- **前置**：必答，0~120，仅整数。
- **输入**：`abc`、`12.5`、`-1`、`121`、`30`。
- **预期**：前四次 `400`，分别提示合法数字、必须整数、不能小于 0、不能大于 120；
  `30` 通过。
- **实际**：通过。

### T14 跳转规则校验

- **输入**：单选条件值 `z`（不存在）；目标指向自己。
- **预期**：分别提示「有效的选项」「只能跳转到后面的题目」，规则不写入。
- **实际**：通过。

### T15 统计聚合与权限

- **前置**：2 份已提交答卷；单选、多选、文本、数字各一题。
- **输入**：bob 选 `a`、`[a,b]`、`hello`、`20`；carol 选 `b`、`[b,c]`、`world`、`30`。
- **预期**：总提交 2；单选各 50%；多选 B 为 100%；文本包含 hello/world；
  数字平均 25.0；carol 访问统计返回 404，alice 返回 200。
- **实际**：通过。

### T16 文本答案分页

- **前置**：2 份提交，文本分别为 hello/world；`STATS_ANSWER_LIMIT=1`。
- **步骤**：打开第 1 页、`?page=2`、`?page=999`。
- **预期**：第 1 页「第 1 / 2 页」且只出现一个答案；第 2 页另一个答案；
  `?page=999` 回退到第 2 页。
- **实际**：通过。

### T17 草稿不计入统计

- **步骤**：已有 2 份提交后，bob 再开始一份并只答 Q1，不提交。
- **预期**：统计仍显示 2 份。
- **实际**：通过。

### T18 CSRF 防护

- **前置**：开启 `CSRF_ENABLED=True`。
- **步骤**：无 Token POST `/register`；GET 页面提取 `_csrf`；带 Token 重新提交。
- **预期**：第一次 `400` 且含「CSRF」；第二次成功并提示「注册成功」。
- **实际**：通过。

## 5. 真实 HTTP 端到端

`tools/e2e_smoke.py` 使用 `requests.Session`，走真实 Cookie、CSRF 和重定向：

1. 创建者注册 → 创建问卷 → 添加 3 题 → 添加「选 A → 第三题」规则 → 发布；
2. 实名用户注册 → 开始填写 → 选 A，断言跳到第三题、第二题被跳过 → 提交；
3. 匿名用户注册 → 勾选匿名 → 走同样跳转 → 提交；
4. 创建者查看统计，断言同时包含实名/匿名文本答案和 2 份提交；
5. 清理测试数据。

实际输出摘要：

```text
1. 创建者注册与问卷管理
  PASS  注册 e2e_owner_xxxxxx
  PASS  创建问卷
  PASS  添加题目：第一题（跳转条件）
  PASS  添加题目：第二题（应被跳过）
  PASS  添加题目：第三题（跳转目标）
  PASS  详情页包含 3 道题目
  PASS  添加单选跳转规则
  PASS  发布问卷
  PASS  解析公开链接

2. 实名用户填写（含跳转）
  PASS  开始填写并进入答题页
  PASS  选择 A 后跳到第三题
  PASS  第二题被跳过
  PASS  答完后进入检查页
  PASS  实名提交成功

3. 匿名用户填写
  PASS  匿名开始填写
  PASS  匿名选择 A 后跳到第三题
  PASS  匿名提交成功

4. 查看统计
  PASS  统计页返回 200
  PASS  统计页包含实名文本答案
  PASS  统计页包含匿名文本答案
  PASS  统计页显示 2 份已提交答卷

E2E 冒烟测试全部通过（23 项）。
测试数据已清理。
```
